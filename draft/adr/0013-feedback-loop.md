# ADR-0013. 피드백을 하나의 대장으로 모으고 효과를 확인한다

상태: 창업자 결정 (2026-11-26). 우선순위 공식과 기간은 제안

## 결정

회고, 리뷰, 검증 실패, 사고, 문의, 창업자 수정·거절, 결정 재검토, 지표 경고를 하나의 대장에 모은다.
고친 뒤에는 미리 정한 성공 신호로 효과를 다시 잰다. 같은 원인이 다시 나오면 순위를 올린다.
창업자의 수정과 거절은 학습 후보로만 쓴다.

## 이유

루프가 문서마다 따로 있어 결과가 모이지 않았다. 고친 뒤 효과를 확인하지 않았다. 창업자의 기준이 기록되지 않았다.

## 대가

8시간과 1주가 늘어난다. 주간 15분의 관리 시간이 든다. 항목이 많아지면 대장 자체가 짐이 된다.

## 다시 검토할 조건

4주 뒤 우선순위 공식과 기준값을 실제 결과로 다시 정한다. 주간 15분을 두 주 연속 넘으면 항목을 묶거나 버리는 규칙을 더한다.
