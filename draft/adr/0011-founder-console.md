# ADR-0011. 로컬 웹 콘솔과 별도 승인 페이지를 쓴다

상태: 콘솔, 실시간 진행, 요약, 대시보드는 창업자 결정 (2026-11-25). 승인 페이지 분리와 패스키 병합 확인도 같은 날 확정. 세부 보안 값은 제안

## 결정

창업자의 기본 화면은 `localhost` 웹 콘솔이다. 구현은 AX 실행으로, 탐색은 터미널로 한다.
콘솔은 조회와 제한된 작업 명령만 가진다. 승인은 다른 OS 사용자로 실행되는 승인 페이지에서 한다.
R0와 R1의 병합도 승인 페이지에서 패스키 한 번으로 확인한다. 페이지를 만들기 전에는 `ax-publish` 사용자의 터미널 확인을 쓴다.

## 이유

창업자는 작업, 회사, 서비스를 한곳에서 판단해야 한다. 같은 PC의 다른 프로그램이 클릭을 흉내 내는 것도 막아야 한다.

## 대가

P1~P3에 웹 화면과 보안 시험이 더해진다. R0와 R1의 병합에도 기기 동작이 한 번 필요하다.

## 다시 검토할 조건

휴대폰 조회를 연다. 자동 병합이나 무인 실행을 검토한다. 실시간 이벤트의 빠짐이 C-01을 넘는다.
