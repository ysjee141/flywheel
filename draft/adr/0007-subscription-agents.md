# ADR-0007. 구독형 코딩 에이전트로 시작한다

상태: 창업자 결정 (2026-11-24). 아래 운영 방식은 제안

## 결정

LLM API를 쓰지 않는다. Claude Code 월 20달러 구독으로 시작한다. API 예산은 0이다.
Codex, Gemini CLI, Kiro는 필요할 때 어댑터로 더한다. LLM API 연결은 나중에 별도 ADR로 연다.

## 운영 방식 (제안)

- 창업자가 지켜보는 감독 모드로 시작한다. 무인 실행은 끈다. 동시 작업은 1개다.
- 에이전트 프로세스는 호스트에서 구독 로그인을 쓴다. 에이전트가 실행하는 명령만 샌드박스에 넣는다. 강화 설정에서 동작을 확인했다([실측](../evidence/claude-sandbox-2.1.331.md)). 규격은 [12](../12-supervised-mode.md)다.
- 이 방식에서는 에이전트의 파일 도구가 샌드박스 밖에서 돈다. 권한 규칙과 감독이 필요하다. 호스트에 프로덕션 자격증명을 두지 않는다.
- 달러 대신 5시간·주간 한도, 시간, 턴으로 작업을 제한한다.
- 리뷰 구성은 창업자가 확정했다(2026-11-24). R1은 Claude 새 세션, R2는 Claude 새 세션과 무료 Codex다.
- 창업자가 데이터 설정을 마쳤다고 밝혔다(2026-11-25). 남은 조건은 V-05와 한도 확인이다.
- Codex의 V-05와 한도를 확인하기 전에는 비공개 코드를 보내지 않는다. 그동안 R2는 `blocked`다.

## 다시 검토할 조건

P1에서 R2 대기가 잦으면 안전 관련 코드만 R2로 남기는 안을 검토한다. 아직 채택하지 않았다.
무인 실행이 필요하거나, 구독 한도로 4주 연속 계획 작업의 50%를 끝내지 못한다.
