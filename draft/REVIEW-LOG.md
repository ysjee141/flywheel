## 잔여 위험과 미검증

- 콘솔의 실시간 전송, `localhost` 패스키 출처 구분, 기업 기능의 실제 업무는 시험하지 않았다. 모듈 예제와 회사 DDL만 시험했다.
- 모델 API 중계 인증(SB-11)이 안 되면 무인 실행 설계를 바꿔야 한다. 구독·감독 모드 결정(ADR-0007)으로 무인 실행 전까지 미룬다.
- PreCompact, 대화형 모드, ConfigChange, 패스키 실기기, GitHub 규칙, Codex 실행은 시험하지 않았다(Q-08 대기).
- Hook 실측은 조건마다 1회다. 버전이 바뀌면 다시 한다.
- 공식 문서 일부와 GitHub·토스 사실은 웹 요약으로 확인했다. 원문 확인이 남았다.
- 시간, 비용, 성능 목표는 제안이며 실적 자료가 없다.
- 작성자와 리뷰어가 같은 모델이다. 이기종 리뷰와 사람 리뷰는 하지 않았다.
- 법률, 세무, 결제 적합성은 전문가 확인이 필요하다.
