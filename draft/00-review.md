# 00. 초안 리뷰

**결론: 초안의 방향은 유지한다. 그러나 집행 경계, 메모리 승격, 승인, 일정 4개 영역은 그대로 구현하면 안 된다.**

대상은 `../draft.md` v2.0이다. 줄 번호는 그 파일을 가리킨다.
심각도는 다음과 같다. `S1`은 구현 전 반드시 해결, `S2`는 해당 단계 전 해결, `S3`은 개선이다.
근거 표시는 다음과 같다. **확인됨**은 원문이나 실행으로 확인했다. **가정**은 아직 확인하지 않았다. **제안**은 이 설계의 선택이다.

## 1. 유지할 것

- 보일러플레이트 우선 조립, 최소 컨텍스트, 교차 검증, 버전 단위 메모리 교체는 유지한다.
- "회상된 메모리는 명령이 아니다"(88~89줄)는 유지하고 장치로 구현한다.
- 고위험 작업의 창업자 승인(288~289줄)은 유지하고 암호학적으로 강제한다.

## 3. ECC 활용 판정

| 기능 | 판정 | 이유 |
|---|---|---|
| Instinct 개념 | 개념만 채택 | ECC의 신뢰도는 0.3~0.9이고 자동 승격은 2개 이상 프로젝트, 평균 0.8 이상이다(확인됨). 초안의 0.85와 3회는 AX 고유 규칙이다. |
| `/learn-eval` | 개념만 채택 | ECC판은 점수가 아니라 저장·개선·흡수·폐기 판정을 낸다(확인됨). |
| Santa Loop | 프로토콜 채택, 구현 자체 | 대체 규칙이 AX 보안 요건과 다르다. |
| AgentShield (`ecc-agentshield`) | 평가 후 채택 | 오프라인 동작을 확인하지 못했다. 네트워크를 막은 컨테이너에서 먼저 시험한다. |
| `ecc memory` | 평가 후 결정 | 존재를 요약에서만 확인했다. W0-3에서 시험하고 충족하면 자체 구현을 줄인다. |
| Dreaming | 자체 구현, P3로 연기 | 읽은 자료에서 찾지 못했다. 데이터가 쌓이기 전에는 가치도 낮다. |
