# Claude 명령 샌드박스 실측 (2.1.331, WSL2, 2026-11-24)

방법: 소형 모델, `claude -p`, 조건마다 1회, 카나리 파일. `socat`은 시스템에 설치하지 않고 임시 폴더에 풀어 PATH로 줬다. 홈의 임시 시험 폴더는 삭제했다.

| 확인 | 설정 없음 | `enabled` | 강화 |
|---|---|---|---|
| 작업 폴더 밖(홈) 읽기 | 가능(`/tmp` 시험) | **가능** | 차단 |
| 작업 폴더 밖(홈) 쓰기 | 미시험 | 차단 | 차단 |
| `/tmp` 아래의 다른 폴더 쓰기 | 가능 | **가능** | 미시험 |
| `/mnt/c` 읽기 | 가능 | **가능** | 차단 |
| 원시 TCP | 가능 | 차단 | 차단 |
| Docker 소켓 | 미시험 | 차단 | 차단 |
| Windows `cmd.exe` | 미시험 | 실패(vsock) | 없음 |
| `.git/hooks` 쓰기 | 가능 | 차단 | 미시험 |
| 부모 환경 변수 | 보임 | **보임** | **보임** |

강화는 `denyRead: ["~/", "/mnt"]`, `allowRead: ["."]`를 더한 것이다.

- 현재 시스템에는 `socat`이 없다. `failIfUnavailable: true`면 시작을 거부했다. 없으면 경고 뒤 **샌드박스 없이** 실행됐다.
- `socat`이 깨져 있으면 시작은 되지만 명령을 거부했다.
- 파일 도구는 이 샌드박스 밖이다. `Read`는 권한 규칙 `deny: ["Read(~/**)"]`로 막혔다. `socat`이 없어 샌드박스가 꺼진 상태에서는 `denyRead`만으로 막히지 않았다.
- [12](../12-supervised-mode.md)의 설정을 그대로 실행해 V-01~04를 1회씩 확인했다. `env -i`에서 카나리 환경 변수는 0건이었다. V-04는 `~/.claude` 하나만 시험했다. V-05는 시험하지 않았다.
- 미시험: 허용 도메인, 대화형 모드, 파일 도구의 쓰기, 상징 링크, 자원 제한.
